# OUTPOST ZERO — Architecture & Engineering Decisions (DECISIONS.md)

| ID | Date | Decision | Rationale |
|---|---|---|---|
| **ADR-001** | 2026-11-25 | Maintain zero breaking changes to legacy `src/` and `windows/` while building `Engine/`, `Game/`, `Shaders/`, `Tools/`, `Tests/` cleanly beside them | Preserves existing working 66-test Web/WinUI3 baseline (Section 4 non-destruction rule) until native feature parity is achieved |
| **ADR-002** | 2026-11-25 | Phase 1 Bootstrap depends exclusively on Win32 + DXGI 1.6 + DirectX 12 + DirectXMath + DXC (`dxc.exe` from Windows SDK `10.0.26100.0`) + C++20 STL, while `vcpkg.json` declares pinned Phase 2+ packages (`entt`, `joltphysics`, `d3d12-memory-allocator`, `spdlog`, `fastgltf`, `directxtex`, `imgui`, `recastnavigation`, `gtest`) gated behind CMake feature toggles | Guarantees fast, deterministic, offline-safe compilation (`< 10s`) and live DX12 verification in Phase 1 while pinning dependencies cleanly as subsystems unlock |
| **ADR-003** | 2026-11-25 | Right-handed vs Left-handed coordinate standardization: standardize **ZERO Engine** on **Left-Handed Y-Up (`+X` Right, `+Y` Up, `+Z` Forward, 1 world unit = 1 meter)** matching DirectXMath `XMMatrixLookToLH` / `XMMatrixPerspectiveFovLH` | Eliminates sign-inversion bugs across HLSL shaders, DX12 clip-space depth `[0, 1]`, Win32 input yaw/pitch, and Jolt Physics adapters |
| **ADR-004** | 2026-11-25 | Three frames in flight (`kFramesInFlight = 3`) paired with per-frame `ID3D12CommandAllocator`, linear `UploadRingBuffer`, deferred resource retirement queue, and monotonic fence completion tracking | Prevents CPU/GPU pipeline stalls and avoids destroying resources still referenced by in-flight DX12 command lists |
| **ADR-005** | 2026-11-25 | Always compile HLSL Shader Model 6.0 shaders offline at build time via Windows SDK `dxc.exe` into `Shaders/*.cso`, with hardware adapter selection preferring highest dedicated VRAM discrete GPU (RTX 3050) and clean WARP software fallback flag | Enables immediate validation of DXIL shaders at build time and reliable execution even in headless/software environments |
