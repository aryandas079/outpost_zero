# OUTPOST ZERO — Refactoring & Enhancement Plan

## Phase Execution Roadmap

| Phase | Focus Area | Key Deliverables |
|---|---|---|
| **Phase 0** | Baseline Audit & Documentation | Full repository inspection, live browser baseline capture, `CODEBASE_AUDIT.md`, `KNOWN_ISSUES.md`, `PERFORMANCE_BASELINE.md`, `REFACTOR_PLAN.md`. |
| **Phase 1** | Critical Repairs & `tsc` Fix | Resolve 4 `tsc --noEmit` errors; fix sky/storm-wall seam & ocean horizon cutoff; fix banner clipping, minimap label clutter/rotation/nested button, tactical map clipping/overlap, and BR modal copy. |
| **Phase 2** | Modular Architecture (`src/`) | Refactor monolithic `engine.ts`, `battleRoyaleIsland.ts`, `TitleOverlay.tsx` into `core/`, `rendering/`, `world/`, `entities/`, `gameplay/`, `physics/`, `animation/`, `audio/`, `input/`, `networking/`, `assets/`, `ui/`, `settings/`, `utilities/`, `tests/` with compatibility re-exports for existing tests. |
| **Phase 3** | 10 km² Island Redesign & Streaming | 14 differentiated POIs with unique silhouettes & multi-route enterable layouts; higher-precision chunked terrain with LOD + stochastic anti-tiling shader/splatting; real Hydro Dam reservoir & continuous river to coast; 3D elevated road splines, bridges over river, markings, poles, fences; multi-species instanced vegetation with exclusion checks; custom animated GLSL water with Fresnel, waves, shoreline foam, and depth color; spatial chunk streaming. |
| **Phase 4** | Sky, Lighting & Models | High-res horizon-coherent atmospheric sky dome + soft clouds + distance haze; calibrated PBR sun/IBL/shadow cascades/adaptive shadow distance; refined C-130 aircraft proportions, matte tactical livery, animated props/lights; enhanced PBR viewmodels & gloved hands. |
| **Phase 5** | Battle Royale Gameplay & Lifecycle | Explicit match state machine (`loading` -> `lobby` -> `airdrop` -> `freefall` -> `parachute` -> `grounded` -> `eliminated`/`spectating` -> `victory`/`results`); loot & inventory system (ground weapons, ammo, armor plates, meds, grenades, interaction `[E]`, dropping); multi-phase deterministic valid storm zones; staggered terrain/LOS-aware AI bots; complete match cleanup & restart. |
| **Phase 6** | HUD, Minimap, Tactical Map & Menus | Neutral `#10161D` military FPS HUD aligned to wireframe; north-up/rotating minimap toggle & clustered markers; interactive zoom/pan/waypoint Tactical Map synced 1:1 with world terrain/coastline/roads/POIs; streamlined Main Menu, Pause confirmation, categorized Settings (Graphics/Display/Audio/Controls/Gameplay/Accessibility), responsive scaling, optional Dev Perf Overlay (`F8`). |
| **Phase 7** | Native C++ / C# / WinUI 3 Windows App | Replace Electron dependency for Windows desktop with `windows/OutpostZero.Native` (C++20 DLL: DXGI GPU/VRAM telemetry, raw mouse & cursor confinement, MMCSS game-mode timer) + `windows/OutpostZero.WinUI` (C# WinUI 3 XAML + `WebView2` virtual host + native bridge + hardware/crash diagnostics + `launch-windows.bat`). |
| **Phase 8** | Optimization, Testing & Validation | Automated unit/edge-case tests (`npm test`, `tsc --noEmit`), production Vite build, WinUI 3 + C++ build, live browser verification across gameplay states & resolutions, before/after screenshots, updated `docs/` & `ASSET_CREDITS.md`. |
